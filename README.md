# Hypr–Payo

**Hypr–Payo** es un repositorio que contiene configuraciones para las tres principales herramientas estéticas de Hyprland: su propia configuración y la de Waybar y Rofi.

---

## Qué incluye

* **Compositor:** Hyprland versión 0.55 en adelante — configurado en **`hyprland.lua`**.
* **Barra superior:** Waybar — separada con diferentes píldoras.
* **Lanzador de apps:** Rofi.

## Estructura en `~/.config/`

Para evitar problemas y tener un escritorio payo, mantén el siguiente orden en tu máquina.

```text
~/.config/
├── hypr/
│   └── hyprland.lua
├── waybar/
│   └── config.jsonc
│   └── style.css
└── rofi/
    └── theme.rasi
```
